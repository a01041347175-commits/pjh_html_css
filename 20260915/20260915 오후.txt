html 종료

CSS언어
적용방법 1. 인라인 : 태그에 직접 스타일링(html 태그 안에 직접 CSS작성)
적용방법 2. 내부스타일 : head 안에 작성
적용방법 3. 외부파일 : link 타입에는 href(가지고오는 css의 경로), rel(어떤 부분), type 의 속성을 가진다 - 가장 선호하는 방법

css 란(cascading style sheet)
마크업 언어(html)가 데이터 구조를 하면 스타일링을 하는 언어
css기본 문법
선택자{속성:속성값;}
b(선택자){color(속성):#0000ff;(속성값)}
b {
   color: #ccc;
}

*색상 : 16진수 색상 코드값(RGB_빛으로 전달/CMYK_인쇄물)
선택자 : 전체, 태그, 클래스, 아이디, 자식/후선, 동위 등등

전체선택자 : *{}
